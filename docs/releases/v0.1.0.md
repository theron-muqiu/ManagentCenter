# v0.1.0 首次发布

ManagentCenter 基础后台首版，提供前后端分离的系统管理能力，暂不包含具体业务模块。

- Vue 3、TypeScript、Element Plus 前端，使用官方默认组件样式及中文界面。
- Java 21、Spring Boot、Spring Security 后端，MySQL 保存业务数据，Redis 保存 Token 登录会话。
- 用户、角色、权限管理，菜单树与权限树支持展开收起。
- 用户角色分配、角色权限分配、用户启停、本人改密及管理员重置密码；密码修改后全部旧登录失效。
- 操作记录与登录日志查询；日志保存失败不阻断原业务。
- 提供环境变量模板、本地依赖配置、部署示例及中文需求、设计、任务和实现文档。

最近一次代码验证：后端 39 项测试通过；前端 21 项组件测试通过，TypeScript 检查及生产构建通过。未执行浏览器端到端测试。

启动与环境配置见根目录 README。此版本标签表示源代码发布，不代表应用已部署到生产环境。
